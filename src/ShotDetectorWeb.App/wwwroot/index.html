Shot detector

Finds the cuts in an MP4, in your browser. The same shots as scenedetect, byte for byte, and the file never leaves this machine.

ShotStartEndLength

Everything runs here, in your browser: .NET on WebAssembly, in a web worker. ManagedCodecs reads the MP4 and decodes the H.264, ShotDetector.FastYuv converts the frames, ShotDetector finds the cuts. The player above is your browser's own; the shots are not. Nothing leaves this machine: no upload, no analytics, no server but the one these files came from.
